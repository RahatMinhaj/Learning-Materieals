# Amazon EC2 Instance

Amazon EC2 is AWS's virtual server service. Follow the lessons in order.

## Learning path

1. [EC2 Complete Guide](amazon-ec2-complete-guide.md)
2. [Formatted HTML version](amazon-ec2-complete-guide.html)

## Topics covered

- EC2 architecture
- Regions and Availability Zones
- AMIs and instance types
- VPCs, subnets, routes, and IP addresses
- Security groups and network ACLs
- SSH and Systems Manager Session Manager
- Opening ports and port forwarding
- IAM roles and instance metadata
- EBS storage and snapshots
- Web-server deployment
- Load balancers and Auto Scaling
- Monitoring, backups, and troubleshooting
