# AWS Identity and Access Management (IAM)

Cloud identity, permissions, policies, roles, and access security. Follow the lessons in order.

## Learning path

1. [IAM Complete Guide](amazon-iam-complete-guide.md)
2. [Formatted HTML version](amazon-iam-complete-guide.html)

## Topics covered

- What IAM is and its core building blocks
- Users, groups, roles, and instance profiles
- Policy types (identity, resource, managed, inline, boundaries, SCPs)
- Policy JSON structure and evaluation logic
- IAM roles in depth (EC2, Lambda, cross-account, service roles)
- Federated access, IAM Identity Center (SSO), and MFA
- Access keys and programmatic access
- IAM Access Analyzer, Policy Simulator, and CLI
- Troubleshooting `AccessDenied`
- Security best practices and audit checklist
